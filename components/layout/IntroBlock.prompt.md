The one part of the page meant to be rewritten per recipient — name, discipline, who it's addressed to, and a single large statement.

```jsx
<IntroBlock
  discipline="Creative direction & content"
  addressedTo="For Outfitters — Spring 26"
  statement="I make apparel campaigns that look like they came from somewhere."
  contact="Karachi · bilal@example.com · open to project work"
/>
```

`name` renders as plain type — there is no logo mark. Swap `addressedTo` + `statement` per pitch and leave the case studies untouched.
