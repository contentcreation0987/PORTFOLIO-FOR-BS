The system's one loud element — an oversized, tightly-tracked grotesque title; use exactly one at size 1 per case study.

```jsx
<DisplayTitle size={1} balance>Movement × Lyari Drop</DisplayTitle>
<DisplayTitle size={3} as="h3">Execution</DisplayTitle>
```

Sizes 1/2/3 map to `--fs-display-1/2/3`. `tone="on-media"` when set over a reel. Do not add colour — titles are always ink.
