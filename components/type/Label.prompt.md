One-line uppercase eyebrow that names a block or numbers a case study — use it above every Passage and DisplayTitle, never for sentences.

```jsx
<Label index="01">Movement × Lyari Drop</Label>
<Label>Brief</Label>
<Label tone="on-media">Reel 02 · muted</Label>
```

Variants: `tone` quiet | ink | accent | on-media. `index` prints a brass number before the text. `as` for semantics (`as="h2"`).
